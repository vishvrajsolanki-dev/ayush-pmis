# Contributing to AYUSH

## Git Protocol
- Branch naming: feature/<desc>, fix/<desc>, docs/<desc>, refactor/<desc>
- Commit format: <type>: <subject> (types: feat, fix, docs, refactor, test, chore)
- Pull Request: create branch, push, open PR, address feedback, merge

## Before Pushing
- Tests pass: cd backend && pytest
- Code follows project standards
- Commits follow format
- Branch name follows convention

## Questions?
Check docs/ for technical specifications or ask in team channels.
